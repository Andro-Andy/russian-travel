# Техническое задание

## Проект «Путешествие по России»

### 1. Описание проекта

Необходимо разработать адаптивный одностраничный веб-сайт на тему путешествий по России.

Основная задача проекта — реализовать интерфейс максимально близко к предоставленному дизайн-макету в Figma с корректным отображением на различных разрешениях экрана.

Проект является практической работой, направленной на закрепление навыков адаптивной вёрстки, работы с изображениями, файловой структурой и современными подходами к организации CSS.

---

### 2. Дизайн и макет

В качестве основного источника дизайна используется макет в Figma.

В макете представлены версии проекта для различных размеров экранов, включая desktop и mobile.

При реализации необходимо учитывать:

- размеры и расположение элементов;
- типографику и размеры шрифтов;
- отступы и интервалы;
- ширину и ограничения контейнеров;
- изображения и их пропорции;
- поведение элементов на различных разрешениях;
- соответствие визуальному стилю макета.

**Макет в Figma:**

[Открыть макет](https://www.figma.com/file/5S2WSbEFL6awjVWJ0NWL8Q/Sprint-3_-Russia-_-desktop-mobile?node-id=28503%3A0)

---

### 3. Основные требования

#### 3.1. Адаптивность

Сайт должен корректно отображаться на различных устройствах и разрешениях экрана.

Необходимо обеспечить полноценную адаптацию:

- для широкоформатных мониторов;
- для ноутбуков и планшетов;
- для мобильных устройств.

Верстка должна быть гибкой, без появления горизонтальной прокрутки и критических визуальных искажений.

#### 3.2. Соответствие дизайну

Все основные элементы страницы должны соответствовать макету Figma.

Особое внимание необходимо уделить:

- точности позиционирования;
- размерам блоков;
- расстояниям между элементами;
- размерам текста;
- межстрочным интервалам;
- изображениям;
- адаптивным изменениям интерфейса.

---

### 4. Изображения

Изображения необходимо самостоятельно извлечь из макета Figma.

Перед использованием на сайте все изображения рекомендуется оптимизировать для веба с целью уменьшения размера файлов и ускорения загрузки страницы.

Для оптимизации можно использовать сервис:

[TinyPNG](https://tinypng.com/)

При оптимизации необходимо сохранить достаточное качество изображений и корректное соотношение сторон.

---

### 5. Структура проекта

Рекомендуемая организация файлов:

```text
project/
├── index.html
├── images/
├── blocks/
├── pages/
├── vendor/
└── README.md
```

Структура может быть адаптирована в зависимости от используемого подхода и требований проекта.

При написании CSS рекомендуется придерживаться методологии **БЭМ** и разделять стили на логические блоки.

---

### 6. Требования к HTML/CSS

HTML-разметка должна быть семантичной и логичной.

Необходимо использовать подходящие семантические элементы:

`header`, `main`, `section`, `footer`, `nav` и другие — там, где это уместно.

CSS должен быть организован таким образом, чтобы:

- избежать большого количества повторяющихся правил;
- сохранить понятную структуру проекта;
- обеспечить корректную адаптивность;
- упростить дальнейшее редактирование и поддержку кода.

Не рекомендуется использовать абсолютное позиционирование для построения всей страницы. `position: absolute` следует применять только там, где оно действительно необходимо согласно дизайну.

---

### 7. Производительность

Сайт должен загружаться максимально быстро.

Для этого необходимо:

- оптимизировать изображения;
- не использовать изображения большего размера, чем требуется;
- избегать ненужных ресурсов;
- следить за размером CSS и других подключаемых файлов.

---

### 8. Проверка результата

Перед публикацией необходимо проверить:

- корректность отображения на разных разрешениях;
- отсутствие горизонтального скролла;
- соответствие макету Figma;
- работоспособность ссылок;
- корректность отображения изображений;
- валидность HTML/CSS;
- отсутствие критических ошибок в консоли браузера.

---

---

### 10. Критерии готовности

Проект считается выполненным, когда:

**Дизайн**
Интерфейс визуально соответствует макету Figma.

**Адаптивность**
Страница корректно работает на desktop и mobile-разрешениях.

**Код**
HTML и CSS имеют понятную структуру и аккуратную организацию.

**Изображения**
Все необходимые изображения извлечены из макета и оптимизированы.

**Функциональность**
Все предусмотренные макетом ссылки и элементы работают корректно.

**Публикация**
Готовая версия сайта доступна по публичной ссылке.

---

### 11. Итоговая цель

В результате необходимо получить полностью адаптивный, визуально аккуратный и технически корректный веб-сайт **«Путешествие по России»**, соответствующий утверждённому макету Figma.

Проект следует рассматривать не только как готовую страницу, но и как практическую работу по освоению профессионального подхода к созданию веб-интерфейсов.
